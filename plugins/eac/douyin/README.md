# EAC 抖音内容台

抖音内容运营台：选题、素材、视频脚本与分镜、发布计划（本地），以及经由**你已登录的创作服务平台网页**（CDP）的发布。

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 选题 / 素材 / 视频脚本 / 分镜 / 计划 | production | 保存于插件工作目录 `douyin-desk.json` |
| 发布视频 | experimental | 规则里设 `auto` 直接发，设 `manual`（默认）进待审批队列；两种都写审计 |
| 作品管理页数据读取 | experimental | 依赖网页结构；改版后「自检」会指出哪一项不再匹配 |
| 数据指标 | unavailable | 抖音未向个人创作者开放数据接口，不做推断 |
| 验证码与风控 | unavailable | 遇到安全验证一律暂停并交给本人处理，不做破解或指纹伪装 |

## 配置

`config.json`：

- `accountId`：平台账户连接 id（在「平台」页面创建账户后填入）。
- `cdpUrl`：DevTools 地址，例如 `http://127.0.0.1:9222`，需指向一个你已登录抖音的 Chrome。
- `serverUrl` / `serverToken`：本应用的服务地址与令牌。
- `selfName`：账户在抖音上的显示名。

## 发布边界

默认 `manual`：发布请求进入待审批队列，由你在看板确认后才执行。改成 `auto` 后由插件直接发布，仍写审计、仍受限额约束。两种模式下，页面一旦要求登录或安全验证都会立刻停下并上报，不会绕过。

计划（`dy-plan`）只是本机日程，不代表已经发布。
