# EAC 贴吧助手

贴吧运营台。贴吧没有开放的读写接口，因此全部经由**一个你已登录贴吧的 Chrome**（CDP）操作真实页面。

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 接收回复通知并交给 Bot | production | 轮询回复页，投递到宿主 `/api/platforms/inbound`；Bot 回复从 `/outbox` 取回 |
| 读取吧内帖子与楼层 | experimental | 依赖网页结构；改版后「自检」会指出哪一项不再匹配 |
| 回帖草稿 | production | 保存于插件工作目录 `tieba-drafts.json`，单条上限 500 字 |
| 发表回帖 | experimental | 规则里设 `auto` 直接发，设 `manual` 进待审批队列；两种都写审计 |
| 验证码与风控 | unavailable | 遇到安全验证一律暂停并交给本人处理。不做破解、不做指纹伪装 |

## 配置

`config.json`：

- `accountId`：平台账户连接 id（在「平台」页面创建账户后填入）。
- `cdpUrl`：DevTools 地址，例如 `http://127.0.0.1:9222`，需指向一个你已登录贴吧的 Chrome。
- `serverUrl` / `serverToken`：本应用的服务地址与令牌。
- `selfName`：账户在贴吧上的显示名。

## 为什么不内置 Cookie 或 tbs

贴吧的登录态与 `tbs` 这类发帖令牌都会随会话变化。放进插件配置，就要在这个进程里保管并刷新它们；留在你自己的浏览器里，插件只驱动页面，凭据不出浏览器。

## 页面改版怎么办

看板的「运行网页自检」会逐项探测选择器，报告哪一项没命中、页面是否在要求登录或安全验证。选择器集中在 `web/parse.mjs`，改版时只改那一个文件。
