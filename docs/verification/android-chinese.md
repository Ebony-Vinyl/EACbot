# 安卓客户端中文化

本次改动影响范围是安卓配对、任务、会话、终端、桌面、设备设置和通知展示模块。

将用户可见普通英文替换为中文，保留产品名、模型标识、协议字段和命令。同步更新三处通知测试的预期文案，通知仍不携带任务正文或审批详情。

## 验证

在主工作区对相同安卓文件执行：

`JAVA_HOME=... ANDROID_HOME=... ./apps/android/gradlew -p apps/android :core:test :app:testDebugUnitTest :app:assembleDebug --console=plain`

151 项测试和调试 APK 构建通过。本轮仅修正已有通知测试的英文断言，不新增业务逻辑。分支复制后核对与已测试源文件一致。

未进行真机、模拟器视觉验收或签名发行包构建；本 PR 未提供安卓截图。界面当前直接使用中文，未新增安卓多语言切换机制。
