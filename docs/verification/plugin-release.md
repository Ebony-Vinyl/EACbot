## 环境

沿用[验证入口](README.md)和[平台验收](plugin-platform.md)。分发测试使用临时签名密钥、loopback 假源和空白 EAC fixture；不得复用生产签名密钥。恶意归档放各自空目录，受信检查脚本在其他目录，不运行下载物中的脚本。

正式 staging 的目录、端口、服务用户与数据全部隔离；生产只在获准切换后做只读检查，不在生产验证发送、安装、卸载和迁移失败。

## 安全阻断

以下任一未解决不得发行：跨工作区/账户/受众泄漏、明文秘密、任意文件逃逸、无效签名激活、权限绕过、撤销后继续外发、重复交易/消息、不可恢复数据损坏或 Tauri/插件无签名更新生效。

不同平台的外围能力缺失可以标为不可用而单独发行其他模块，但发行说明必须与 UI 一致；不能把受限模块也打勾为“全部完成”。

## 证据清单

每份报告包括：revision、依赖/制品摘要、schema/API/state 版本、OS/CPU、Node/.NET/桌面版本、用例 ID、具体命令与动作、fake 服务版本、状态前后、日志路径、截图/录屏、真实外部回执、失败/跳过原因、恢复步骤。

秘密、账号 Cookie、真实用户消息、内部部署地址不进入仓库和公开报告。需要的部署参数来自环境或受控运行手册，不硬编码。
