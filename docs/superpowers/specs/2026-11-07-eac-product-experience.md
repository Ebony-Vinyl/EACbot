# EACbot 产品与界面设计

日期：2026-11-07。状态：目标设计，未实现。结构与安全边界见[总体架构](2026-11-07-eac-plugin-platform-design.md)，业务行为见[集成设计](2026-11-07-eac-integrations-design.md)。

## Context

扩展、平台 Bot、任务、音乐与面板应像同一个产品，而不是互不相干的网页集合。界面参考 Magpie 的目录和用量组织、用户提供的应用分类截图，以及 Hark 的自然语言面板体验；使用 EAC 自己的品牌与资产，不复制闭源代码/素材。

## 1. 信息架构

```text
左侧：Bot 与工作区                 主区域                       上下文区（可收起）
个人助手                         会话 / 平台看板 / 任务         当前任务、审批、产物
  我的 Bot                       与当前 Bot 关联               播放与工具状态
平台 Bot
  QQ 助手      [QQ]
  B站探索      [B站]
  闲鱼运营     [闲鱼]
工具入口
  任务中心 · 我的面板 · 扩展 · 用量 · 设置
```

平台 Bot 是现有 Bot 实体的绑定模式；不再造一套与主聊天不相通的侧边栏。账户支持授权给现有 Bot，不强制每连接一个平台就增加条目。边栏分组可调整、排序与置顶，平台标识不能取代用户自定义头像。

连接状态用图标和文字共同表达，不能仅靠红/绿。隐藏只改变导航可见性，提示“后台任务仍运行”；暂停、解绑与删除使用不同菜单和说明。

### 1.1 独立平台 Bot 创建

连接账户 → 测试连接 → 选择“授权已有 Bot”或“新建平台 Bot” → 设置名称、头像、模型、自动行为 → 选择记忆空间 → 完成。

默认私有记忆。共享选择显示空间名称、成员、读/读写及可见数据范围；不提供默认勾选的“所有 Bot 共享所有记忆”。将个人偏好提供给平台 Bot 时解释外部群聊受众限制。

## 2. 扩展中心

```text
扩展中心                           [渠道管理] [本地开发包]
[搜索名称、能力、作者                              ]
发现    已安装    更新
全部 · 功能 · 模型 · 通讯 · 国内平台 · 语音 · 音乐 · 外观 · 设备
（国内平台选中）QQ · B站 · 闲鱼 · 抖音 · 小红书 · 贴吧

[图标 名称 / 作者]   [功能摘要]    [支持宿主 / 审核状态]    [安装]
[图标 名称 / 作者]   [功能摘要]    [已安装 / 需配置]        [管理]
```

分类是一层，平台筛选是二层，账户列表不挤在同一 tag 行。保留现有 Connected apps 与 MCP 可达入口，逐步映射到同一目录/连接模型，而不是让用户重新登录。

搜索覆盖名称、能力、平台和作者；结果显示来源。自定义源离线时只标记该源失败，不清空其他结果。无结果给清除筛选/管理渠道入口，不能伪造推荐数据。

### 2.1 详情与安装

详情页展示功能、预览、作者、来源 URL/指纹、版本记录、许可证、支持平台、依赖、权限、数据去向、维护状态及已知限制。

安装步骤：来源/版本 → 权限说明 → 下载验证 → 安装禁用 → 配置/登录 → 选择 Bot/设备 → 激活测试。取消时说明已完成阶段和保留状态；不能显示“100%成功”但后台仍未配置。

按钮区分安装、连接、启用、升级、重试、禁用、卸载。新增权限用差异列表突出，升级不可把授权问题藏在 changelog。

### 2.2 渠道管理

列出渠道名、URL、指纹、最后成功同步、缓存状态、版本/撤回检查。新增自定义源需确认信任；换钥和同 ID 换源单独提示。禁用源说明不会自动卸载包，并说明停止获知新撤回的影响。

## 3. 平台看板

所有平台共享头部：账户选择、连接状态、主处理 Bot、自动行为模式、最近同步、暂停入口。主体按业务设计，不机械复制相同 KPI 卡片。

| 平台 | 主体内容 | Bot 联动 |
| --- | --- | --- |
| QQ | 左侧会话，中间消息/待回复，右侧策略与审批 | 当前对话调用工具、点歌、任务，来源可追踪 |
| B站 | 内容发现/订阅、阅读队列、带来源摘要、日报 | 添加研究任务、回看时间点、选择写入兴趣空间 |
| 闲鱼 | 会话待办、商品、订单可用信息、草稿与异常队列 | 商品知识回复、规则授权、计划执行与结果核验 |
| 抖音/小红书 | 选题/素材、内容计划、草稿、发布与指标能力状态 | 创建选题任务、改写草稿、申请发布 |
| 贴吧 | 主题/吧、帖子阅读、摘要、回复草稿 | 兴趣任务、来源引用、限额与验证暂停 |

没有实际接口支持的区块显示“未开放/未配置/实验能力”及原因，不以可点击假按钮或示例指标冒充真实支持。删除/发布等操作展示具体账户和目标。

点击“交给 Bot”把当前选择作为有来源的数据引用传入该 Bot 会话，不另开一个失去权限上下文的匿名聊天。看板更新、Bot 工具结果和任务详情都使用同一服务状态。

## 4. EAC Muse 界面

Muse 页面以音乐为中心：当前封面/歌曲、进度、播放控件、队列、歌词、歌单/搜索；Bot 建议作为一条可解释的推荐区，不遮挡播放控制。

对话内播放卡显示歌曲、来源、目标设备、状态与必要控件，和 Muse 页面共享实际播放器状态。正在请求、等待浏览器手势、设备离线、已播放、受限曲目必须区分。没有播放回执时不能显示“正在播放”。

长期偏好可查看、更正和清除；当前会话要求单独显示。Bot 推荐说明引用真实依据，不虚构歌曲 BPM/情绪数据。TTS 插播时可显示“Bot 正在说话，音乐暂时降低音量”；用户可始终手动暂停。

## 5. 任务中心与用量

Kanban 使用紧凑但可读的卡片：标题、负责 Bot、来源平台、优先级、下一执行时间、阻塞原因、必要费用信息。任务列为待分拣、待办、已计划、就绪、运行、阻塞、待验收、完成；归档是筛选，不是额外状态列。

运行状态来自执行器，不能把卡片拖到“运行中”便假造开始。拖拽非法转换说明原因；并发修改返回新版本，用户不丢失未保存文字。窄屏切换列表/分组，避免八列挤成一屏。

用量中心提供时间范围、Bot/模型/供应商/插件/任务维度、趋势、明细与导出。免费、未知、估算和实付用不同标签；TTS/STT/视频按实际单位，不都折成 token。趋势没有数据时显示零条记录，不生成装饰曲线。

## 6. 自然语言面板

用户“创建面板” → 描述需求 → Bot 提议布局与数据源 → 检查权限 → 预览 → 保存/继续调整。

PanelSpec 包括 schemaVersion、panelId、title、layout、components、dataSources、actions。数据源引用注册能力；布局绑定受信组件，类型包括 metric/chart/table/list/timeline/kanban/form/markdown。拒绝任意 SQL、脚本或未授权 URL。动作确认不能由模型自行取消。

每个面板显示来源、刷新时间与错误，支持拖动/调整大小、版本历史、复制、导出及删除。保存版本与实际权限分离：导入别人面板不导入其授权。缺依赖时保留布局并显示恢复入口。

高级 HTML 面板运行在独立 frame，样式不能污染外壳。PanelSpec 模型生成失败返回可编辑说明，不偷偷降级为执行任意代码。

## 7. 外观与布局插件

主题提供颜色、字体、密度、圆角、阴影、动效 token；布局通过命名插槽组合已授权内容。界面风格可切换，而非只能换背景色。

内置提供浅色和深色的可靠回退；卸载当前主题/布局立即回到内置。审批、身份、权限警告和安全恢复条不可隐藏。新增主题不通过注入任意全局 CSS 修改页面。

设置中提供“暂时禁用第三方界面”安全模式，入口不依赖第三方加载成功。插件 UI 的异常边界按贡献点隔离，其他会话仍可用。

## 8. 视觉与交互规范

- 方向：精致、克制的工作台。暖灰浅色、石墨深色、EAC 品牌强调色，不使用泛滥渐变/大面积玻璃效果。
- 保持现有排版体系，优先本地字体和中文可读性；不为了样式引入远程字体追踪。
- 以 4/8px 间距尺度、明确的标题/正文/辅助文字层级统一布局。普通正文以 14–16px 为设计基准，说明文本不能因信息多而无限缩小。
- 桌面主测试 1280×800、1440×900；窄屏 390×844；低宽度切换抽屉而不是溢出。
- 交互状态覆盖 default/hover/focus/pressed/disabled/loading/empty/error/offline/permission-denied/success。
- 过渡以 160–240ms 的 transform/opacity 为主，减少 layout thrashing；减少动态效果模式取消非必要动画。
- WCAG AA：普通文字至少 4.5:1，大字和关键图形至少 3:1；键盘可达、可见焦点、语义名称和状态朗读。
- 拖拽提供键盘或菜单替代；关闭抽屉恢复焦点；加载状态不重复朗读整页。
- 图标/截图有稳定宽高，减少内容跳动；大量目录/任务采用分页或虚拟化，不一次绘制全部。

性能作为待测目标：在注明设备与数据量的 fixture 上，常规交互反馈 p95 ≤100ms、关键过渡尽量保持 60fps；不把目标写成已实现指标。测量包括低性能模式和冷启动，不只截静态图。

每个页面提供明暗主题、空/错/加载/权限不足截图；市场安装、看板切换、Kanban 拖拽和 Muse 插播提供录屏。截图不能替代操作结果，自动测试也不能替代视觉检查。
