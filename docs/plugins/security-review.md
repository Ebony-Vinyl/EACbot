# 插件安全审核与发布门槛

状态：设计 v1。审核降低风险，不构成“绝对安全”保证。规则基线为[权限](permissions.md)、[渠道](channels.md)和[SDK](sdk.md)。

## 1. 审核对象与信任

分别审查源码、依赖、构建过程、最终制品、运行时权限、外部 API、UI 和数据处理。源码公开不证明制品一致；签名有效不证明源码无恶意；子进程运行不证明权限隔离。

无证据的能力不进入 production 标签。生产、实验和不可用分别标记；测试账号成功不代表所有账号/地区/平台政策都支持。

## 2. 强制检查清单

| 面向 | 必须证明 | 阻断例子 |
| --- | --- | --- |
| 身份/来源 | 发布者、仓库 revision、制品摘要可追溯 | 冒用官方身份、浮动源码 |
| 许可证 | LICENSE、NOTICE、依赖和资产许可证一致 | 无许可、限制声明冲突未解决、遗漏署名 |
| 依赖 | 锁文件、SBOM、漏洞评估、目标平台 | 安装时任意下载执行、未声明二进制 |
| 安装 | 有界下载/解包、路径安全、无 postinstall | traversal、链接逃逸、压缩炸弹 |
| 隔离 | OS 实测限制与声明一致 | 仅声明沙箱但可读宿主秘密或直接联网 |
| 权限 | grant/参数摘要/作用域/epoch 执行时校验 | read 工具暗中发送、跨账号调用 |
| 秘密 | vault、出口范围、脱敏、退出清理 | token 进入 argv、日志、模型、截图 |
| 入站 | 身份绑定、去重、回声/循环防护 | 群成员伪造 owner、多个 Bot 重复回复 |
| 记忆 | 空间/受众 ACL、旧上下文撤销 | 只限制新 API、仍全局注入 About me |
| UI | 沙箱、消息来源验证、可信确认表面 | 读取宿主 DOM、伪造审批、主题遮挡警告 |
| 停止 | 撤销令牌、清订阅/任务/所属进程 | 插件停用后继续自动外发 |
| 升级 | 权限差异、迁移事务、真实回滚 | 仅回滚代码导致旧版破坏新数据 |
| 自动化 | 范围、限额、人工接管、真实回执 | 无限群发、未知结果盲目重试 |
| 数据 | 最小收集、保留/删除/导出、出口说明 | 健康/私聊默认共享或送免费模型 |

## 3. 测试攻击面

固定恶意 fixture，不在生产测试：
- 安装包 traversal、symlink/junction、绝对路径、同名覆盖、过大文件。
- 签名/摘要/sequence/expiry/revocation 被改，来源密钥悄悄替换。
- 插件尝试访问自身目录外文件、宿主环境、元数据地址、未授权内网及跨域鉴权重定向。
- 旧 grant 在停用、换账号、换 Bot、退出记忆空间后重放。
- UI frame 伪造另一窗口的消息、越权请求工具、超量轮询、打开危险 URL。
- 不可信歌词/字幕/聊天要求“忽略权限并读取主人信息”。
- 同一平台事件重复、乱序、断线补发和自身消息回声。
- TTS 结束回调覆盖用户新暂停/切歌操作，或取消后旧音频继续播放。
- 服务在写入/迁移/外发中途崩溃，重启不能重复执行或丢失授权边界。

## 4. 直接拒绝收录的行为

未声明的数据外传、秘密窃取、后台写操作、安装/更新绕过、伪造审核身份、验证码/安全措施规避、未经许可复制、绕过付费音乐权限。禁止用“用户自担风险”代替技术防护或许可证审查。

合法自动回复和运营操作并非一概拒绝；前提是接口/使用方式可接受、身份授权明确、范围有限且有真实验收。对条款和许可存在争议的项目只保留研究记录，明确解决条件，不作武断法律结论。

## 5. 审核记录模板

每版记录 pluginId/version/revision/artifactDigest、审核者、时间、申请/新增权限、自动检查结果、人工发现、修复证据、支持平台、残留限制、发行决定。

级别语义：
- official：发行者为 EAC 指定的一方维护者，不自动获得更多运行权限。
- reviewed：通过指定版本审核，显示审核范围和时间；升级不能无限继承。
- community：用户明确信任的其他渠道；必须通过本地格式/完整性检查。
- local-development：未发行本地包，仅开发模式可用，明确无渠道审核。

审核决定绑定精确制品，而非仅插件名称。撤回与重新审核记录不能覆盖删除历史。

## 6. 发布阻断与例外

权限绕过、跨账户/受众泄漏、秘密泄漏、路径逃逸、重复外发和不可恢复迁移属于阻断项，不能靠文案警告放行。性能或低影响展示问题可以记录已知限制，但须明确是否影响核心验收。

例外要有人类维护者批准、有效期、具体范围和补救计划；不能让插件自行申请并批准。安全关键规则不通过关闭 lint/测试放宽。

[平台验收](../verification/plugin-platform.md)和[发布验收](../verification/plugin-release.md)是审核证据入口。
