# 兼容性、迁移与恢复

状态：设计 v1。目标是增加插件而不破坏现有 Bot、模型、MCP、TTS、记忆和桌面桥。

## 1. 四类版本独立

| 版本 | 用途 |
| --- | --- |
| manifest schemaVersion | 包描述格式；未知 major/格式拒绝 |
| plugin version | 插件 SemVer，绑定不可变制品 |
| apiVersion / service version | 宿主与服务合同范围；握手检查 |
| stateVersion | 持久数据格式；迁移事务负责 |

禁止用插件版本推断数据格式，或用同一文件名覆盖不同摘要。新增字段若改变权限语义不能当作“可忽略”。弃用 API 至少跨两个宿主 minor 版本保留兼容与警告，重大安全问题可紧急撤回并附迁移通知。

## 2. 现有功能的适配顺序

1. 先用测试锁定当前行为，增加注册表和适配器，不改变默认配置。
2. 纯主题/面板与一个现有工具能力走新合同，证明安装和卸载闭环。
3. 将现有 TTS provider、应用连接卡片等逐项注册为一方插件，保持旧 ID、配置读取和 UI 入口兼容。
4. 为旧配置增加可逆转换；读取时检测版本，写入时带版本，迁移记录一次性结果。
5. 避免双注册和双消费：一个能力在一个时刻只有一个负责实例；旧路径由明确 feature gate 关闭。
6. 迁移稳定后才删除兼容分支，附回归与数据恢复证据，不以“重构”跳过行为测试。

不要同时提取所有社区下载器或所有驱动；先复用可靠原语，再在有重复需求和合同测试时合并。

## 3. 私有与共享记忆迁移

现有 `MEMORY.md`、topic、日志和 About me 继续可读，默认仍属于原范围。新增空间不自动吸收全部历史；用户选择共享的条目才复制/引用并增加 provenance 和 ACL。

账户/外部群聊接入前，审计旧系统 prompt、About me、文件工具、session_search 与自动召回的出口。不能用“仅新共享空间安全”掩盖旧注入路径泄漏。若某引擎不能重新构建上下文或约束工作目录，则对相应外部受众拒绝受限记忆功能。

退出空间改变授权 epoch，取消/阻断旧检索；缓存键包含 workspace、Bot、principal、audience、空间 revision 和 epoch。删除索引、派生摘要与历史对话的语义分别说明，不能把“停止检索”说成“外部数据已删除”。

## 4. 更新事务与回滚

每次升级有 installation 互斥锁和事务日志，步骤为下载验证、预检、停止旧版本、快照、工作副本迁移、启动新版本、探测、原子提交。崩溃后根据提交标记恢复；没有成功提交就不能将新状态标记为 active。

快照必须可恢复且避免包含无保护秘密。不可逆迁移必须明确备份依赖和恢复步骤；自动更新拒绝此类版本。回滚同时匹配代码、配置、状态格式与依赖，不仅切换版本号。

旧 grant 对新增权限不生效，外部动作不能“回滚”。更新前已发送的消息仍然存在，恢复不重放发送队列，结果不明进入核验队列。

## 5. 宿主兼容矩阵

| 宿主 | Bot 服务 | 播放/麦克风 | 系统能力 |
| --- | --- | --- | --- |
| 浏览器 + 服务器 | 在服务器执行 | 经用户授权的浏览器设备 | 受浏览器限制，自动播放需要手势 |
| Electron 本地 | 现有 Node 子进程 | 本地能力 | 维持现有桥接合同 |
| Tauri 本地 | 同一 Node 服务，不重写核心 | 按平台验证的音频/权限 | 新 HostAdapter，透明桌宠、托盘、更新分别验收 |
| Tauri 连接服务器 | 在远端执行 | 当前配对桌面提供 | 远端不天然拥有本地文件/输入设备权限 |
| 后续原生手机/手表 | 本轮未实现 | 未来平台授权 | 当前仅协议与模拟器，不宣称真实支持 |

保留 `src/types/ogb.d.ts`、`electron/bridge-contract.json` 的兼容约束。Tauri 适配不需要假造全部能力；未实现部分报告 unsupported，UI 必须降级，旧 Electron 测试继续通过。

## 6. 模型与多模态兼容

模型列表仅发现模型 ID，不证明 TTS/STT/视频支持。供应商适配器声明接口、编码、流式、取消与计量单位，并通过 fake 合同测试；实际账号再做授权检查。

OFM 公开能力和用户服务器 New API/NVIDIA 配置分别登记。不存在的接口显示 unavailable，不由客户端猜测路径。兼容驱动不得把音频/视频当普通文本发送并声称支持。

## 7. 最小发布标准

新旧数据夹具、版本不兼容、权限增加、停用后旧 token、迁移中断、卸载当前主题/布局、Linux/Windows 路径差异都必须测试。真实 OS 未测试即标未验证；不能只因构建成功宣称安装、桌宠与播放可用。
