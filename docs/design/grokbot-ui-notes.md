# Grok Bot 0.18 交互研究笔记

研究日期 2026-11-15。对象：`b-nnett/grok-bot-0.18-reconstructed`、`ChHsiching/grok-bot-0.18-original`、`adam91holt/grokbot-sdk`。本文只记录交互结构、状态机与体验规则，不复制任何源码、CSS 类名、图标、截图或整段文案。

## 许可结论

- 两个 grok-bot 仓库都没有 LICENSE：一个是非官方二进制重建，一个是带 Anysphere 版权的反编译归档，均不授予代码权利。只能研究交互，不能复制代码、素材或成段文案。
- `grokbot-sdk` 是 MIT，但只是 host 客户端 SDK，不授予 Grok Bot 产品界面权利。
- 三个仓库都没有手机端、配对、QR、设备信任或移动推送 UI。手机端设计不能声称来自它们。

## 可借鉴的桌面结构

- 三段式：左侧 bot 列表，中间会话，右侧信息/电脑面板；电脑预览与全屏共享同一状态源。
- 侧栏折叠保留 88 px 图标轨道；面板关闭延迟约 240 ms 卸载，保证退场可见，但立即失去交互。
- 每个 bot 行有四种互不抢占的状态：工作中、等你、离线、错误；“等你”优先于未读，且不与“工作中”同时显示。
- 命令面板统一搜人、消息、文件、链接、任务与动作，是桌面导航中枢。
- 多 bot 关系图只画真实委派历史；两端都在运行时连线发亮。

## 云电脑控制

- 三级呈现：会话内交接卡 → 右栏实时预览 → 全屏可操作画布。同一 controller，状态只有一份。
- 状态：off、starting、sleeping、local、running、pulling；另有读取态 unknown/known/error。状态请求有硬超时，超时进入错误，不无限转圈。
- 画面用容器比例缩放，不能对画面做 transform 缩放，否则指针坐标漂移。键盘与画面分别追踪 focus 归属。
- 交接卡三种结果：Take over、I'm done、Skip。Skip 必须与完成在视觉上可区分，且明确说明“agent 会跳过这一步”。
- 断线保留最后画面 + Reconnecting + Retry，不清空会话。重连不重放旧输入。
- 多屏只列正在运行且有画面的 computer 子 Agent；当前屏被移除时回退到有交接请求的屏，再回退第一屏。
- 剪贴板、键盘映射、远端输入必须走受控通道；敏感操作与人工接管要有明确控制权租约。

## 通知

- 只在两种转变通知：agent 开始等你、agent 完成且不是在等你。
- 窗口/设备活跃时静默；同类事件短窗节流；按消息 id 去重；正文截断，锁屏不显示敏感内容。
- 点击通知必须打开对应 bot 与会话，而不是当前页面。

## 动效

- 交互反馈约 120 ms；浮层/卡片入场约 160–180 ms，位移仅约 4 px，缩放约 0.98；面板宽度约 240 ms；大位移约 500 ms 强减速。
- 状态点变化用约 130 ms 弹性曲线；不做无限呼吸。
- 关闭保留退场时间但不延迟交互禁用；始终提供 reduced-motion 分支。
- 不为了“像”而添加毛玻璃。EACbot 的模糊只用于自有背景和既有玻璃原语。

## 手机端建议

- 采用“bot 列表 → 会话 → 该 bot 的电脑卡片”三级结构，电脑全屏是二级页面，不照搬桌面三栏。
- 交接请求同时走系统通知与会话内卡片，点击直达 bot 与 thread。
- 弱网保留最后已知会话与最后画面 poster；明确显示离线与最后同步时间。
- 横屏全屏时软键盘不得遮挡画面；提供缩放、键盘、剪贴板与退出；控制权与桌面端互斥。

## 不采用

- 厂商账号、商业云、套餐/席位/试用、供应商路由与付费墙。
- Boat 类共享云电脑与供应商广告。
- 反编译 bundle、哈希 CSS 类名、图标字体、截图、英文原文。
- 将桌面 Dock 角标或隐藏 bot 逻辑直接搬到手机。
